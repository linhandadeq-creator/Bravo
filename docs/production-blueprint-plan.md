# 方案：面向实验室生产的 mRNA 图纸引擎（高合格率）

目标定位：平台输出的不再只是"模拟示意图"，而是一份**可分发给实验室、用于生产/验证的图纸包（Production Blueprint Package）**，并尽可能提高下游**合格率（synthesis + expression + immunogenicity 成功率）**。

> 前提声明：合格率最终由**湿实验**决定。软件负责把"可制造性"与"表位质量"做到最大化并给出量化放行标准；真实合格率需通过**基准集 + 实验数据闭环**校准。

---

## 1. 交付物定义（Definition of Done）

一份"生产图纸包"包含：

1. **优化后序列**（DNA/RNA）与区域注释。
2. **元件表（Feature Table）**：5' cap、5'UTR、Kozak、信号肽、表位盒、连接子、终止、3'UTR、poly(A)。
3. **序列级 QC 报告**：量化指标 + **PASS/FAIL 放行判定**（硬阈值）。
4. **生产指令**：IVT 模板、引物、克隆/酶切位点、LNP 配方参数、放行检测项（由序列真实推导）。
5. **候选/表位证据表**：binding/processing/presentation、Class II、MS 证据、表达、自身过滤。
6. **溯源与方法学**：工具/模型/参考数据版本 + checksum。
7. **实验设计工作单**：候选与对照，供实验板布局。

---

## 2. 系统架构（新增模块）

```
NeoantigenCandidate ──► BlueprintDesignEngine ──► SequenceQC(release) ──► ProductionPackage ──► 导出/报告/工作单
                                   ▲                      ▲
                        EpitopeQuality ──────────── 证据(MS/表达/HLA)
```

- `app/blueprint/design.py`：约束式序列设计引擎。
- `app/blueprint/sequence_qc.py`：序列级 QC 与放行判定。
- `app/blueprint/package.py`：生产图纸包（元件表/IVT/引物/LNP/放行）。
- `app/blueprint/worklist.py`：实验设计工作单 + 对照。
- `app/services/evidence.py`：证据聚合（MS/表达/pMHC 稳定性/人群覆盖）。

## 3. 序列设计引擎（v1 约束，默认值）

| 约束 | 默认 |
| ---- | ---- |
| GC 含量 | 目标 40–60%，硬边界 30–70% |
| 同聚物 | 禁止 ≥ 5（硬 ≥ 6） |
| 直接重复 | 禁止 ≥ 10 bp；去低复杂度 |
| 限制性酶切位点 | 去除常用酶（EcoRI/BamHI/HindIII/XhoI/NotI…）与 Type IIS（BsaI/BsmBI，按克隆策略） |
| 隐蔽剪接 | 避免剪接供体/受体 PWM 高分位点 |
| 加尾信号 | 去 AATAAA/ATTAAA 等 |
| 免疫刺激 motif | 去已知 stimulatory motif |
| 5' 二级结构 | 5'UTR ΔG 阈值（弱结构） |
| 密码子 | CAI ≥ 0.8；稀有密码子阈值 |
| Kozak | GCCACC(A/G) |
| poly(A) | 设计化长度（如 100–120 bp，可配置） |
| 连接子 | 避免 junctional epitope；选低免疫原性 spacer |

优化策略：以 CAI 为目标、在约束下做确定性/随机重启搜索，输出**最佳可行序列**；不可行则报告冲突项（不静默）。

---

## 4. 序列级 QC 与放行（硬门槛）

- 计算：GC 分布、最长同聚物、最长重复、低复杂度、RE 位点、剪接 motif、加尾信号、5' 二级结构 ΔG、CAI、隐藏 ORF。
- 输出 **Manufacturability Score（0–100）** + 每项 PASS/FAIL。
- **只有全部硬约束通过才标记 `PRODUCTION_READY`；否则 `DESIGN_FAILED`**（不静默）。

---

## 5. 生产图纸包（真实推导）

- IVT 模板序列（含 T7 启动子）与引物设计。
- 克隆/酶切策略（按所选载体）与连接片段。
- LNP 参数模板（摩尔比、N/P、粒径目标）。
- 放行标准（浓度、完整度、加帽/加尾效率、封装效率、无菌）——标注"模拟/待实验确认"。
- 所有段落由**序列与配置推导**，带版本与输入 hash。

---

## 6. 表位质量（决定免疫原性合格率）

- Class I（MHCflurry，已接）+ **Class II**（NetMHCIIpan 或兼容环境）。
- **多预测器一致性**（≥2 工具取交集/加权）。
- **MS/免疫肽组证据**（IEDB 等）。
- **pMHC 稳定性**、**人群 HLA 覆盖率**。
- 自身/交叉反应过滤（UniProt 人类蛋白组，已接）→ 扩展为相似度搜索。

---

## 7. 实验设计工作单

- 候选表：肽段、长度、HLA、预测指标、表达、特异性、self 标记。
- 建议对照：通用阳性肽、无关阴性肽、随机自肽。
- 多肽池/串接布局（板位映射）。

---

## 8. 阶段路线

| 阶段 | 内容 | 依赖 |
| ---- | ---- | ---- |
| **P1（软件，可立即做）** | 序列设计引擎 + 序列级 QC + 生产图纸包 + 工作单导出 | 无（纯软件） |
| **P2（软件+资源）** | Class II + 多预测器一致性 + MS 证据 + 人群覆盖 | 授权工具/数据库 |
| **P3（资源）** | BAM→体细胞、真实 HLA 分型/RNA 定量、离线库 | conda/docker + 参考基因组/库 |
| **P4（湿实验闭环）** | ELISpot/四聚体/质谱/表达；量化并校准合格率 | 实验室 + 样本 |

---

## 9. 合格率策略（关键）

- 软件把"可制造性/表位质量"最大化 → 提升**预期**合格率。
- 定义可量化指标：合成成功率、表达滴度、免疫原性命中率。
- 先用 **P1 输出 + 小规模试点**得到基线；再用实验数据**回填阈值/权重**迭代。
- 用基准集（TESLA/NCI/HiTIDE）校准 PPV/敏感性。

---

## 10. 风险与合规

- 风险：过度优化导致加工/免疫原性下降；单工具偏差；上游假阳性。
- 缓解：多工具一致性 + MS 证据 + 实验兜底；明确标注不确定度。
- 合规：图纸标注"研究用/未验证/非人体"；合成、动物、人体需 IBC/IRB 与生物安全审批。

---

## 11. 验收标准（P1）

- 对任一 AnalysisRun 可生成 `PRODUCTION_READY` 图纸包（含序列、元件表、QC 指标、IVT/引物、LNP、放行、Methods、工作单）。
- 序列级 QC 所有硬约束可判定且可复现；不通过时给出明确失败项。
- 报告/导出（JSON/Markdown/HTML/PDF/CSV）包含量化可制造性指标。
- 测试覆盖：优化约束、QC PASS/FAIL、图纸包结构、确定性。
